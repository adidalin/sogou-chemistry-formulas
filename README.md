# 搜狗输入法 · 初中化学式自定义短语

> 一套适用于**搜狗输入法**的初中化学式快捷输入配置文件，涵盖单质、氧化物、酸、碱、盐、离子、有机物共 7 大类，约 167 条化学式。

## 快速开始

1. 打开搜狗输入法状态栏 → 右键 → **更多设置**
2. 进入 **高级** → **自定义短语** → 勾选启用
3. 点击 **直接编辑配置文件**
4. 将 `搜狗输入法_初中化学式_最终版20260509.txt` 的全部内容粘贴进去
5. 保存，重新加载输入法即可生效

## 配置文件格式说明

```
拼音,序号=化学式
```

- **拼音**：化学式对应的中文拼音（小写，无空格）
- **序号**：候选词排序位置（1 表示第一位）
- **化学式**：含上下标的 Unicode 化学式

示例：`lvhuana,1=NaCl` → 输入 `lvhuana` 候选第一位显示 `NaCl`
