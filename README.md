## :jigsaw: 亚铁 / 铁 对照

> :bulb: **中考重点区分 Fe³⁺ 和 Fe²⁺ 的不同化合物！**

| :package: 物质 | :red_circle: 铁 (Fe³⁺) | :green_circle: 亚铁 (Fe²⁺) |
|:--------------:|:---------------------:|:-------------------------:|
| **氧化物** | Fe₂O₃ → `yanghuatie` | FeO → `yanghuayatie` |
| **氢氧化物** | Fe(OH)₃ → `qingyanghuatie` | Fe(OH)₂ → `qingyanghuayatie` |
| **氯化物** | FeCl₃ → `lvhuatie` | FeCl₂ → `lvhuayatie` |
| **硫酸盐** | Fe₂(SO₄)₃ → `liusuantie` | FeSO₄ → `liusuanyatie` |
| **碳酸盐** | — | FeCO₃ → `tansuanyatie` |
| **离子** | Fe³⁺ → `tielizi` | Fe²⁺ → `yatielizi` |

## :gear: 配置文件格式说明

```
拼音,序号=化学式
```

| 字段 | 说明 | 示例 |
|:----:|------|:----:|
| 拼音 | 化学式对应的中文拼音（小写，无空格） | `lvhuana` |
| 序号 | 候选词排序位置（`1` = 第一位） | `1` |
| 化学式 | 含上下标的 Unicode 化学式 | `NaCl` |

> :bulb: 示例：`lvhuana,1=NaCl` → 输入 `lvhuana` 候选第一位显示 **NaCl**
